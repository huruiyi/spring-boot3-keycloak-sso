# Windows Hosts 配置文件位置
# 文件路径: C:\Windows\System32\drivers\etc\hosts
# 需要管理员权限才能编辑

# 添加以下行到 hosts 文件中（如果没有 hosts 文件，请新建一个）：

127.0.0.1 appa.tbk.com
127.0.0.1 appb.tbk.com

# ============================================
# 如何编辑 hosts 文件（Windows）:
# ============================================
# 1. 以管理员身份运行记事本
#    - 右键点击"记事本"图标
#    - 选择"以管理员身份运行"
#
# 2. 打开 hosts 文件
#    - 在记事本中，点击"文件" -> "打开"
#    - 导航到 C:\Windows\System32\drivers\etc\
#    - 在"文件类型"下拉框中选择"所有文件(*.*)"
#    - 选择 hosts 文件并打开
#
# 3. 添加配置
#    - 在文件末尾添加上面两行
#    - 保存文件
#
# 4. 验证配置
#    - 打开命令提示符（CMD）
#    - 运行: ping appa.tbk.com
#    - 应该显示 127.0.0.1
#    - 运行: ping appb.tbk.com
#    - 应该显示 127.0.0.1
# ============================================

# ============================================
# 如何编辑 hosts 文件（Linux/Mac）:
# ============================================
# 1. 打开终端
# 2. 使用 sudo 命令编辑:
#    sudo nano /etc/hosts
#    或
#    sudo vim /etc/hosts
#
# 3. 添加配置行
# 4. 保存并退出
#
# 5. 验证配置
#    ping appa.tbk.com
#    ping appb.tbk.com
# ============================================
